## 运行测试

使用以下命令运行所有仪表板模型测试：

```bash
# 运行所有测试
python -m pytest src/tests/unit/test_dashboard_models_unit.py -v

# 运行特定模型的测试
python -m pytest src/tests/unit/test_dashboard_models_unit.py::TestDashboardConfig -v

# 使用测试脚本
python run_dashboard_model_tests.py
```

## 注意事项

1. **SQLAlchemy默认值**: 在单元测试中，SQLAlchemy的默认值在对象创建时不会自动应用，需要在数据库插入时才会生效。测试中需要显式设置这些值。

2. **Mock对象限制**: 对于复杂的SQLAlchemy关系，使用Mock对象可能会遇到问题，建议使用简单的测试对象或真实的模型实例。

3. **时间相关测试**: 涉及时间的测试需要考虑执行时间差，使用适当的时间范围进行断言。
