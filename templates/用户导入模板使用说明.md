# 用户导入模板使用说明

## 概述
本模板与当前AI测试管理系统的用户表结构完全匹配，支持批量导入用户数据。系统支持Excel (.xlsx, .xls) 和CSV (.csv) 格式的文件导入。

## 字段说明

### 必填字段（Required Fields）
| 英文字段名 | 中文字段名 | 数据类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| username | 用户名* | 字符串 | 3-50个字符，仅支持字母、数字、下划线，系统内唯一 | `user001` |
| email | 邮箱* | 字符串 | 有效邮箱地址，系统内唯一 | `user@example.com` |
| password | 密码* | 字符串 | 至少8个字符，需包含字母和数字 | `Password123!` |

### 可选字段（Optional Fields）

#### 个人信息
| 英文字段名 | 中文字段名 | 数据类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| nickname | 昵称 | 字符串 | 最多50个字符 | `张三` |
| avatar | 头像URL | 字符串 | 有效的图片URL | `https://example.com/avatar.jpg` |
| phone | 手机号 | 字符串 | 11位数字 | `13800138000` |
| bio | 个人简介 | 字符串 | 最多500个字符 | `资深开发工程师` |
| gender | 性别 | 枚举 | MALE, FEMALE, OTHER, UNKNOWN | `MALE` |
| birthday | 生日 | 日期 | YYYY-MM-DD格式 | `1990-01-01` |
| location | 所在地 | 字符串 | 最多100个字符 | `北京市` |
| website | 个人网站 | 字符串 | 有效的URL | `https://mywebsite.com` |

#### 状态和权限
| 英文字段名 | 中文字段名 | 数据类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| is_email_verified | 邮箱已验证 | 布尔 | TRUE/FALSE | `FALSE` |
| is_phone_verified | 手机已验证 | 布尔 | TRUE/FALSE | `FALSE` |
| mfa_enabled | 启用多因素认证 | 布尔 | TRUE/FALSE | `FALSE` |
| is_active | 用户激活 | 布尔 | TRUE/FALSE，默认TRUE | `TRUE` |
| is_superuser | 超级用户 | 布尔 | TRUE/FALSE，默认FALSE | `FALSE` |
| status | 用户状态 | 枚举 | ACTIVE, INACTIVE, DISABLED, LOCKED, PENDING, DELETED | `ACTIVE` |

#### 偏好设置
| 英文字段名 | 中文字段名 | 数据类型 | 说明 | 示例 |
|-----------|-----------|---------|------|------|
| language | 语言设置 | 字符串 | 默认zh-CN | `zh-CN` |
| timezone | 时区 | 字符串 | 默认Asia/Shanghai | `Asia/Shanghai` |
| theme | 主题 | 字符串 | light/dark，默认light | `light` |
| email_notifications | 邮件通知 | 布尔 | TRUE/FALSE，默认TRUE | `TRUE` |
| sms_notifications | 短信通知 | 布尔 | TRUE/FALSE，默认FALSE | `FALSE` |
| push_notifications | 推送通知 | 布尔 | TRUE/FALSE，默认TRUE | `TRUE` |

## 数据格式要求

### 布尔值格式
- 支持：`TRUE`/`FALSE`、`true`/`false`、`1`/`0`
- 推荐使用：`TRUE`/`FALSE`

### 日期格式
- 统一使用：`YYYY-MM-DD`
- 示例：`1990-01-01`、`2023-12-31`

### 枚举值说明
- **gender（性别）**：
  - `MALE`：男性
  - `FEMALE`：女性
  - `OTHER`：其他
  - `UNKNOWN`：未知（默认）

- **status（用户状态）**：
  - `ACTIVE`：活跃（默认）
  - `INACTIVE`：非活跃
  - `DISABLED`：禁用
  - `LOCKED`：锁定
  - `PENDING`：待激活
  - `DELETED`：已删除

## 导入流程

### 1. 准备数据
1. 下载并使用提供的模板文件
2. 删除示例数据，填入真实用户数据
3. 确保必填字段不为空
4. 检查数据格式是否正确

### 2. 数据验证
导入前系统会进行以下验证：
- 必填字段检查
- 邮箱格式验证
- 用户名唯一性检查
- 邮箱唯一性检查
- 密码强度验证
- 枚举值有效性检查

### 3. 导入操作
1. 在用户管理页面点击"导入用户"
2. 选择准备好的Excel或CSV文件
3. 系统会显示预览和验证结果
4. 确认无误后执行导入

## 常见问题

### Q: 密码安全要求是什么？
A: 密码至少8个字符，必须包含字母和数字。推荐包含特殊字符以提高安全性。

### Q: 导入时遇到用户名重复怎么办？
A: 系统会跳过重复的用户名并在导入结果中报告。建议在导入前检查用户名唯一性。

### Q: 布尔字段可以留空吗？
A: 可以留空，系统会使用默认值。但建议明确填写TRUE或FALSE。

### Q: 支持批量更新现有用户吗？
A: 当前版本仅支持新用户导入，不支持批量更新现有用户信息。

### Q: 导入的用户密码需要用户修改吗？
A: 建议导入后要求用户首次登录时修改密码，确保账户安全。

## 注意事项

1. **数据备份**：导入前请备份现有用户数据
2. **测试导入**：建议先用少量数据测试导入功能
3. **权限控制**：谨慎设置is_superuser字段，避免意外授予管理员权限
4. **数据清理**：导入前清理重复和无效数据
5. **字符编码**：CSV文件请使用UTF-8编码以正确显示中文字符

## 技术实现说明

本模板基于当前系统的[`CreateUserRequest`](backend/run_server_async.py:123)模型结构设计，与数据库表结构完全一致。

### 字段映射关系
模板中的字段名与数据库字段名保持一致，确保导入时无需额外转换：

```python
# 必填字段
username -> users.username
email -> users.email  
password -> users.password_hash (自动加密)

# 可选字段
nickname -> users.nickname
avatar -> users.avatar
phone -> users.phone
# ... 其他字段
```

### 数据处理流程
1. 文件上传和格式验证
2. 数据解析和字段映射
3. 业务逻辑验证（唯一性、格式等）
4. 密码加密处理
5. 批量插入数据库
6. 返回导入结果报告
